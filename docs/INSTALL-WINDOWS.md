# Установка Screen Translate на Windows

Инструкция для `ScreenTranslate-0.1.0.2-preview.1-win-x64.zip`, версия пакета **0.1.0.2**. Это self-contained x64 development-layout, **не подписанный MSIX-инсталлятор**.

## Требования

- Windows 11 24H2 или новее, x64, build **26100+**.
- Компонент **English OCR** в языковых параметрах Windows.
- **Developer Mode, включённый самим пользователем** в настройках Windows. Инструкция не включает автоматического изменения настроек безопасности или требования запуска от администратора. Если политика организации запрещает режим, остановитесь.
- Интернет для перевода. Отдельные .NET SDK и .NET runtime не нужны.

## Первая установка

1. Получите ZIP и `SHA256SUMS.txt` из доверенного источника одного релиза. Сверьте SHA-256 ZIP с указанной суммой, например через `Get-FileHash -Algorithm SHA256` с путём к архиву. Совпадение суммы проверяет целостность, но не заменяет доверие к источнику.
2. Выберите **новую пустую постоянную локальную папку** и используйте «Извлечь всё». Не запускайте приложение из ZIP, временной папки или неполной копии. После регистрации папку нельзя перемещать или удалять.
3. Если Windows блокирует загрузку/распаковку/запуск либо показывает предупреждение о неподписанном или неизвестном издателе, не обходите защиту. Проверьте источник и ограничения Windows; при сомнениях остановитесь. Это prerelease без подписанного установщика.
4. Откройте обычный PowerShell **в извлечённой папке, содержащей `AppxManifest.xml`**, и выполните явную регистрацию:

   ```powershell
   Add-AppxPackage -Register .\AppxManifest.xml
   Get-AppxPackage -Name DevLn737.ScreenTranslate |
       Select-Object Name, Version, Status, InstallLocation
   ```

5. Проверьте фактически возвращённые поля: **Status = Ok**, **Version = 0.1.0.2**, **InstallLocation = именно выбранная папка**. Отсутствие ошибки команды само по себе недостаточно. Если пакет не найден или поля не совпадают, не считайте установку успешной.
6. Откройте **Screen Translate через меню Пуск**. Прямой запуск EXE не обеспечивает требуемую package identity для OCR.

## Обновление существующей установки

- Сначала самостоятельно завершите прежнее приложение через **трей → Выход**.
- Сохраните прежнюю зарегистрированную папку до успешной регистрации и проверки нового InstallLocation. Не перезаписывайте её распакованным ZIP.
- Для обновления в другую папку нужна **строго более новая версия пакета**. Если уже установлена **0.1.0.2**, продолжайте использовать текущую зарегистрированную папку: не перерегистрируйте скачанную копию той же версии в другом месте.
- Для более старой установленной версии извлеките новый ZIP в новую пустую постоянную папку и выполните регистрацию/проверку выше. Если установлена более новая версия, не пытайтесь понизить её.
- Перенос той же версии не гарантируется. Не используйте принудительное обновление, downgrade или удаление пакета ради обхода ошибки. Транзакционный rollback Windows-регистрации не обещается; прежнюю папку не удаляйте при неудаче.

## Данные и ограничения

OCR работает локально. По запросу пользователя распознанный текст отправляется Яндексу либо Google; при ошибке — Bing. Снимки экрана не отправляются, история экранов/переводов и телеметрия не ведутся. Настройки хранятся в `%LOCALAPPDATA%/ScreenTranslate/settings.json`; буфер обмена меняется только по команде пользователя. Диагностический `--self-test` отдельно сохраняет отчёт со сгенерированной тестовой фразой.

В этой версии реально проверены packaged self-test на **сгенерированном изображении** и поведение второго запуска. Получены ответы Яндекса и Bing; работоспособность Google не подтверждена. Игровой захват, Home/End/Insert на реальном экране, длинные нативные карточки, HDR, mixed-DPI и длительная работа не проверены. Причина прежнего сообщения о зависании Windows не установлена. Эксклюзивный fullscreen, защищённый контент и ограничения античита не поддерживаются гарантированно; обхода античита нет.
