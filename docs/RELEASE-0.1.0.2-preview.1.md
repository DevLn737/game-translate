# Screen Translate v0.1.0.2-preview.1

**Prerelease**, версия Windows-пакета **0.1.0.2**. Предварительная development-сборка, не проверенный игровой релиз.

Файлы релиза:
- `ScreenTranslate-0.1.0.2-preview.1-win-x64.zip` — автономный x64 layout;
- `SHA256SUMS.txt` — контрольная сумма ZIP.

## Изменения

- Самостоятельный Windows-переводчик EN → RU: WPF, локальный Windows OCR, Яндекс / Google с резервным Bing; без зависимости от Lazy Dictionary, расширения или WebView.
- Стабилизация жизненного цикла запросов, отмены и повторного выделения; разбиение длинного перевода и полного оригинала на страницы с учётом доступного места и DPI.
- Отдельные FIFO-кэши основного и альтернативного перевода, проверка настроек, ограниченная техническая диагностика.
- Сборка в уникальные каталоги без перезаписи прежних layouts; отдельная защищённая проверками регистрация. Различаются обычный второй запуск и `--self-test` при работающем экземпляре.

## Подтверждённые проверки — 11.11.2026

- Ранее: **127/127 C# Release**, **30/30 изолированных PowerShell tests**, **3 × 16/16** повторных async tests. Это результаты предшествующего этапа, не новые прогоны после регистрации.
- Реальная регистрация **0.1.0.2**, Status=Ok; подтверждены Version/InstallLocation. Старый layout (481 файл) и settings.json сохранили контрольные суммы.
- Свежий packaged `--self-test`: **exit 0 / PASS**, Windows OCR сгенерированной фразы и сетевые ответы Яндекса и Bing. **Google не подтверждён**: альтернативный путь использовал Bing fallback; точная причина не сохранена текущей обработкой ошибок провайдеров.
- Обычный второй запуск: **exit 0**, активация настроек исходного процесса, проверены 7 UIA controls и снимок окна. Второй self-test: **exit 2**, без активации настроек/изменения settings или отчёта; исходный процесс продолжил работу.

## Установка и известные ограничения

Windows 11 24H2+ x64 (build 26100+), English OCR и Developer Mode, включённый пользователем. .NET SDK/runtime для ZIP не нужны. Это **не подписанный MSIX**: извлеките всё в новую постоянную папку и зарегистрируйте manifest по [инструкции установки](https://github.com/DevLn737/game-translate/blob/v0.1.0.2-preview.1/docs/INSTALL-WINDOWS.md). При уже установленной 0.1.0.2 сохраните текущую папку, не переносите ту же версию перерегистрацией ZIP.

Self-test **не захватывал рабочий стол**. Реальный Home/End/Insert capture, длинные нативные popup, mixed-DPI, HDR, игры и длительная работа не проверены. Причина исторического зависания Windows не выяснена; релиз не объявляется её исправлением. Неофициальные сервисы перевода могут быть недоступны или менять интерфейсы. Распознанный текст по запросу отправляется сервисам; снимки не отправляются, история экранов/переводов не ведётся.

Полная история и границы доказательств: [VERIFICATION](https://github.com/DevLn737/game-translate/blob/v0.1.0.2-preview.1/docs/VERIFICATION.md).
